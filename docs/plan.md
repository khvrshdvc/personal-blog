# Bosqichlar

Har bosqich alohida branch, commit va qo'lda tekshiruv bilan yopiladi.

1. Muhit: Laravel 11 + Sail (nginx, php-fpm, MySQL, Redis), auth (bitta admin), `.env.example`
2. Ma'lumotlar bazasi: migratsiyalar (posts, projects, settings), modellar, seeder (prototipdagi namuna ma'lumotlar)
3. Layout: Blade komponentlari (tnav, tmini, karta, ⌘K), mavzu almashtirish, dizayn tokenlari
4. Bosh sahifa: bento kartalar (hero, hozir, o'rganyapman, telegram, faollik)
5. Fikrlar, Dasturlash (yozuvlar, loyihalar, faollik), Men, post sahifasi (markdown, mundarija, o'qish vaqti)
6. Admin: login, dashboard, yozuvlar ro'yxati va muharrir (avtosaqlash, pending), loyihalar, sozlamalar
7. Tashqi API: GitHub faollik va Actions, Telegram kanal, keshlash
8. Sifat: testlar, SEO (meta, OG, sitemap, RSS), xavfsizlik tekshiruvi, 404/500 sahifalar
9. Deploy: VPS + Docker, SSL, GitHub Actions orqali avtomatik deploy, zaxira nusxa

## Keyingi qaror kerak
- Admin muharriri: oddiy Blade + JS (boshlang'ich) yoki Livewire
- Hosting: VPS yoki Hostinger
